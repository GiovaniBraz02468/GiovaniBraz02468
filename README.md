## 🚀 Sobre Mim
Desenvolvedor focado em resolver problemas reais através de tecnologia. Atualmente, gerencio o ciclo de vida do **[Cursar.me](https://cursar.me)**, um SaaS construído para otimizar a gestão de estudos, e lidero tecnicamente projetos que utilizam o ecossistema **.NET 8** e **React**.
